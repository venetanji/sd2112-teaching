## F1 / Design Council / framework, not empirical effect

**Design Council. The Double Diamond.** Official resource: https://www.designcouncil.org.uk/resources/the-double-diamond/ . The older `/our-resources/` route redirects here. Official page accessed successfully (HTTP 200). Sections read: How to use the Double Diamond; Evolving with the Framework for Innovation; licensing immediately above the download.

- Discover: understand rather than assume the problem, including people affected.
- Define: discovery insights can redefine the challenge.
- Develop: explore different answers, inspiration and co-design.
- Deliver: test small-scale solutions, reject what does not work and improve what does.
- Framework for Innovation paragraph explicitly permits returning to earlier problem work and making/testing early ideas in discovery. This is not a rigid linear stage gate.
